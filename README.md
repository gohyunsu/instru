# Acapella

목소리의 현재 음과 정확한 반음에서의 센트 편차를 실시간으로 보여주는 모바일 우선 웹 도구입니다.

## 주요 기능

- 마이크 입력을 브라우저 안에서만 분석
- 페이지 진입 시 자동으로 마이크 연결 및 실시간 분석
- 현재 음명, 주파수, 센트 편차 표시
- 시간이 아래에서 위로 흐르는 8초 세로 음정 그래프
- 현재 음 주변의 정확한 반음 재생
- 라이트·다크 테마

## 로컬 실행

ES 모듈과 AudioWorklet을 사용하므로 파일을 직접 열지 말고 로컬 HTTP 서버로 실행해야 합니다.

```bash
python3 -m http.server 4173
```

그런 다음 `http://localhost:4173`을 엽니다.

## 검사

